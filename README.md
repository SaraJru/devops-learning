# DevOps Learning API

A scalable FastAPI application designed to teach DevOps principles and best practices. This project evolves through different phases, progressively introducing more complex DevOps concepts and tools.

## Project Overview

This is a learning project focused on **DevOps best practices**:

- **Phase 1 (Current):** Basic API with Docker and GitHub Actions CI
- **Phase 2:** Automated deployments to cloud platforms
- **Phase 3:** Multi-service architecture with orchestration
- **Phase 4:** Advanced monitoring and infrastructure automation
